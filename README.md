# 🌩️ lab-aws-devops-prep

This repo is where I get my hands dirty with AWS. No Hello World, no clicky-click console — just real Terraform, real infra, and real-world DevOps skills getting sharpened one EC2 at a time. 💥

Part of my **World Domination DevOps Plan™**, this repo includes multiple AWS-focused labs and experiments that cover:

- ✅ Terraform infrastructure from scratch
- ✅ EC2 provisioning with SSH hardening
- ✅ CloudWatch monitoring and observability
- ✅ IAM role-based access and best practices
- ✅ Automated Node.js deployment using `user_data`
- ✅ SSM Session Manager and remote management
- ✅ CI/CD-ready patterns (coming soon)
