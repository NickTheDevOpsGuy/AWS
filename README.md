# 🧠 AWS

This project showcases my ability to deploy, manage, and secure infrastructure in AWS using Terraform, EKS, EC2, S3, IAM, and GitHub Actions, reflecting real-world DevOps practices in cloud-native environments.

> ✅ Built to demonstrate cloud adaptability and CI/CD mastery across platforms.

---

## 🚀 What’s Included

| Feature                         | Description                                                                 |
|---------------------------------|-----------------------------------------------------------------------------|
| 🔧 **Terraform Infrastructure** | Provisioning of VPC, IAM roles, EC2, S3, and EKS using Terraform modules    |
| 🐳 **EKS Deployment**           | Kubernetes cluster bootstrapped for app workloads with GitOps readiness     |
| 🤖 **GitHub Actions CI/CD**     | Secure pipeline using OIDC to deploy infra and apps to AWS                 |
| 📊 **Monitoring**               | AWS-native logging and metrics via CloudWatch with dashboards               |
| 🔐 **Security Practices**       | IAM least privilege, secrets via SSM, and OIDC for secure GitHub workflows |
| 📦 **Reusable Modules**         | Modular and parameterized Terraform for real-world maintainability         |

---

## 🧱 Technologies Used

- **AWS** – EC2, S3, IAM, EKS, CloudWatch
- **Terraform** – v1.8+, remote state, modules, AWS provider
- **Kubernetes (EKS)** – Deployed via Terraform, with GitOps/Helm optional
- **GitHub Actions** – CI/CD with OIDC authentication to AWS
- **CloudWatch** – Metrics, logs, and dashboards
- **SSM Parameter Store** – Secrets and config injection
